# CiCi传讯 Android 工程

本工程把仓库根目录的 CiCi 网页打包为离线 WebView App，并提供网易云媒体会话、录音、文件选择、音乐接口及后台聊天计时所需的安卓桥接。原项目的署名与声明保留在网页中；这是个人修改版。

## 后台聊天

“设置 → 系统 → 后台保活”启用安卓前台服务。App 退到后台时，服务每 2 秒推动一次已到期的聊天回复和邀请任务；安卓要求显示一条常驻服务通知。后台聊天服务首次升级时会开启，以后可手动关闭。它持有 CPU 唤醒锁，长期后台运行会增加耗电。

“后台通知”是独立开关，当前默认关闭。开启并授予系统通知权限后，后台新聊天消息会显示单条通知；点击可进入对应联系人的聊天。关闭通知不会停止后台聊天计时。通知来自本机，不是服务器远程推送。手机强制结束 App 或系统限制后台运行时，服务无法保证继续工作。

后台命中的听歌、看电影和普通邀请先写入聊天；需要用户选择的邀请窗口会在返回 App 后展示，过期后不再弹出。

## 其他安卓能力

- 文件选择器可导入图片、视频和备份文件；拍照、录音、媒体读取会按需请求对应权限。
- 网易云音乐遥控依赖系统通知使用权和网易云公开的媒体会话。先在网易云打开并播放音乐，再由 CiCi 读取和控制。
- 网易云账号登录和在线音源请求在手机端进行；账号凭证保存在本机，不写入仓库。部分音乐接口可能变化，会员歌曲能否完整播放取决于接口实际返回。
- CiCi 自己播放音乐时会使用独立的音乐前台服务；暂停或停止播放后退出该服务。

## 构建

需要 JDK 17、Android SDK 33、Gradle 8.0 和 Node.js。在仓库根目录运行：

```text
node build.mjs
gradle -p android assembleDebug
```

调试 APK 位于 `android/app/build/outputs/apk/debug/`。发布构建运行 `gradle -p android assembleRelease`，并在进程环境中提供 `MOCHI_KEYSTORE`、`MOCHI_STOREPASS`、`MOCHI_KEYPASS`。密钥别名为 `mochi-remote`。签名文件与密码必须留在本机，不能提交到 GitHub。

包名是 `com.mochi.remote`。覆盖安装时，`versionCode` 需比已安装版本更高，并使用同一签名。网页文件由 `android/app/build.gradle` 的 `copyMochiWeb` 任务复制进 APK。

第三方代码许可文本位于 `android/third_party/`。
